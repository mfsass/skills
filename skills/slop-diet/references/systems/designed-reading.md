# Archetype: designed reading

One archetype from the [design references index](../design-references.md). The shared rules there apply. Palette: derive it from the brief's world, restrained, white or warm paper. Use it for docs, guides, articles and readers (Read mode).

The text is the product. Craft shows in measure, rhythm and the tools around the text.

Recipe:
- One column of 60-70 characters, body 17-18px at 1.6 line height, a clear type pairing.
- Navigation left, an on-page contents list right that marks the current section as you scroll. At 390 both fold into one menu.
- Code blocks with a copy button that answers "Copied" inside the button. Callouts for notes and warnings, with an icon and a tint, no side bar.
- One reading tool as the signature moment: highlight to save, a reading progress line, or a live example beside the text.
- Read mode keeps calm paper (white or a light tint). The contrast band is optional: the code blocks or the footer may carry the deep surface.

Example: an API guide. The left nav lists endpoints, the right list follows the scroll, and each request example has a language switch (cURL, JS, Python) that keeps its height across languages. Selecting a sentence shows a small "Save highlight" button.
